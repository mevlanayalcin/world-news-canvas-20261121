## Reproduce

`node main.ts` (Node 22) verifies the committed `1024 × 1024` RGB PNG header, dimensions, IEND marker, and `< 1 MiB` bound, then writes its bytes to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`) with zero network, Python, or font dependencies.

To rebuild locally, run `python3 -B tools/render.py` with Pillow and the Noto Serif, Lato, and Liberation Sans Narrow fonts. The renderer checks strict Saturday UTC evidence timestamps, timeline-to-ledger matching, KPI phrase reconciliation, date-check boundaries, pin separation, text collisions, margins, dateline/caption typography floors, and lossless RGB PNG output.
